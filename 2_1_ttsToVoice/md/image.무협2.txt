3. 이미지 수·타임스탬프 (매칭 기준점 전용 — 라벨 금지)
--------------------------------------------------------------------------------

3-1. SRT 구간 길이 계산
- **첫 SRT 시작초(F)**: 1번 SRT 항목의 시작 시간을 초 단위로 변환 (floor)
- **마지막 SRT 종료초(E)**: 마지막 SRT 항목의 종료 시간을 초 단위로 변환
- **구간 길이(L)**: L = E − F

3-2. 타임스탬프 생성 (내부 기준점만 — 출력 라벨로 사용 금지)

【기본 간격: 20초 (절대 규칙)】
- 타임스탬프: F, F+20, F+40, F+60, …
- 총 타임스탬프 개수 = floor(L / 20) = floor((E − F) / 20)
- ★ 10·15·30초 간격 금지. 반드시 20초. ★

【120초(2분) 배치 — 순차 생성】
- 배치 1개당 최대 6장 (20초 × 6)
- 배치 순서대로 매칭·프롬프트 생성 (총 개수 = floor(L/20) 유지)

★★★ 위 타임스탬프(0,20,40,60…)는 SRT를 고르기 위한 기준점일 뿐.
출력 `SRT_XXX:` 의 XXX에 절대 그대로 넣지 않는다. ★★★

3-3. 마지막 이미지 제한
- 마지막 매칭 SRT 항목 번호 ≤ (전체 SRT 항목 수 − 5)
- 초과 시 해당 타임스탬프는 프롬프트 생성 안 함

3-4. 총 필요 이미지 수
- 공식: **floor((E − F) / 20)**


4. 타임스탬프 → SRT 대본 시작점 매칭 (절대)
--------------------------------------------------------------------------------

목적: SST 라벨·장면이 **대본(SRT)이 실제로 시작하는 시각**에 붙게 한다.
시청자가 그 초에 듣는 자막 = 그 초 라벨의 이미지.

4-1. 기본 규칙
- 1번 SRT 항목부터 매칭 대상
- 각 타임스탬프 T에 SRT 큐 **1개**를 매칭 (중복 선택 불가)
- 매칭 후 라벨·내용은 그 큐에만 종속

4-2. 매칭 알고리즘 (각 타임스탬프 T)

단계 1: 시작시간 ≤ T 인 SRT 중, 아직 미선택 · 시작시간이 **가장 큰** 항목 선택
단계 2: 단계 1 실패 시 → 시작시간 > T 인 미선택 중 시작시간이 **가장 작은** 항목 선택

4-3. ★★★ 매칭 결과 → 라벨 변환 (대본 시작초) ★★★
- 매칭된 SRT의 시작 시간(초)을 floor → S
- 출력 라벨: `SRT_{S, 최소 3자리}:`
  · 00:00:26,400 → S=26 → `SRT_026:`
  · 00:00:58,080 → S=58 → `SRT_058:`  (기준 T=60이어도 ✗ `SRT_060:`)
  · 00:02:29,680 → S=149 → `SRT_149:` (기준 T=150이어도 ✗ `SRT_150:`)
  · 00:18:09,200 → S=1089 → `SRT_1089:`
- floor 충돌 시 뒤 항목 라벨 +1초 조정
- ✗ `SRT_000: SRT_020: SRT_040: SRT_060: …` 처럼 20 배수만 이어지면 **무효** (매칭 미수행)
- ✓ 라벨은 보통 026,058,089,149처럼 **불규칙**하게 나타난다 = 정상

4-4. ★★★ 장면 내용 = 매칭 SRT 대본만 (표시 구간 동기) ★★★

★★★ 이미지 표시 구간 — SRT_XXX 와 대본 일치 ★★★
- 라벨 S = floor(매칭 큐 시작초) → 출력 `SRT_S:`
- 이미지는 대략 **S초 ~ min(S+20, 다음라벨)** 동안 보인다
- **그 구간에 시작·겹치는 모든 SRT 한글 자막** = 이 이미지의 유일한 사건 출처
- 공식: `SRT_S` 프롬프트 사건 ⊆ 구간 [S, S+20) 대본
- ✗ 구간 밖(다음·이후) 대본의 인물·사건을 넣으면 시청자는 지금 대본을 듣는데 다른 이미지가 나와 **불일치 → 무효**

작성 절차 (필수 순서 — 건너뛰기 금지):
1. §4-2로 큐 매칭 → S = floor(시작초) → 라벨 `SRT_S:`
2. SRT에서 **시작시간이 [S, S+20) 인 큐 + S를 덮는 큐**의 한글을 전부 모은다
3. 그 한글만으로 **대본 앵커** 한 문장 (한글, 매칭표용)
   예: 「진무한, 화산 남봉 매화나무 아래 홀로 선다」
4. 앵커 → 영문 주체·객체·행동·장소 (씬 트랙용). 앵커에 없는 것 추가 금지
5. §8 LOOK은 앵커에 그 인물이 있을 때만
6. ✗ 금지: 장 줄거리 균등 배치 · 다음 칸 대본 선행 · “나중에 나올 장면” 미리 그리기

【대본↔SRT_XXX 불일치 — 전부 무효】
✗ SRT_149 대본「진무한 홀로 매화 아래」→ 프롬프트에 Seo Ryeongran
✗ SRT_658 대본「검신이오」→ 프롬프트에 매화 잎 건넴 (~1002초 장면)
✗ SRT_1108 대본이 판·손 이야기 → 어머니 흙집 이미지
✗ 매칭표 앵커와 영문 프롬프트 사건이 다름

【자기검증 — 각 줄 출력 직전】
  (a) 라벨 XXX == floor(매칭 SRT 시작초) ?
  (b) 매칭표에 이 줄의 대본 앵커가 있는가 ?
  (c) 영문 프롬프트 사건 == 그 앵커와 동일 ? (다음 구간 사건 없음 ?)
하나라도 아니면 다시 작성.

13. 주의사항 (필수 준수)
--------------------------------------------------------------------------------

13-1. 입력은 SRT 파일이다. 대본이 아니다.

13-2. 씬 트랙에는 대본/대사 원문을 넣지 않는다.
   ○ 올바른 출력: SRT_026: Chinese wuxia manhua illustration of …
   ○ 허용: 영상 분석 **매칭표**의 대본앵커(한글 한 문장) — 프롬프트 작성용 고정
   ✗ 잘못된 출력: 씬 트랙에 한글 대사 전문
   ✗ 잘못된 출력: SRT_012.png {…}

13-3. ★★★ 씬 트랙 라벨 = 대본 시작초 ★★★
   라벨 = 매칭 SRT 시작초(floor), 형식 `SRT_XXX:` (콜론 필수, .png·{} 금지)
   타임스탬프(F, F+20, …)는 매칭 기준점일 뿐 라벨로 쓰지 않는다.
   정상 출력 라벨은 026,058,149처럼 불규칙하다. 020,040,060만 이어지면 잘못된 것.

13-4. ★★★ 한글·한복 금지 · 글자는 영문/중문만 ★★★
   씬 트랙·이미지에 한글(Hangul) 금지. 인물명은 `Jin Muhan` 등 영문만.
   매칭표 대본앵커만 한글 허용. ✗ `Korean text "…"` 금지.
   이미지에 글자가 꼭 필요하면 English 또는 中文(汉字) 짧은 단어만.
   한글 자막·긴 문장은 SRT 번인·후편집으로만.
   복식: Chinese hanfu만. ✗ hanbok·한복·저고리·치마·갓.

13-5. SRT의 경지·검법·숫자·고유명사는 영문 시각 요소로 프롬프트에 반영한다.

13-6. 1번 SRT 항목부터 매칭 대상이다.

13-7. 마지막 매칭 SRT 번호 ≤ (전체 SRT 수 - 5).

13-8. 말풍선 트리거 동사 금지.

13-9. ★★★ 간격은 반드시 20초 · 120초 배치 순차 생성 ★★★

13-10. 등장인물은 §8 Character Bible LOOK만 사용 (Jin Muhan 등 영문 이름), Chinese wuxia manhua only.

13-11. ★★★ SRT_XXX = 그 초 대본 (스토리보드·다음 대본 선행 금지) ★★★
   매칭표 완성 → 씬 트랙. 각 `SRT_XXX`는 표의 대본앵커([XXX, XXX+20) 한글)만 그린다.
   장 후반 사건(어머니·무혼·두번째 판 등)을 앞 칸에 미리 배치하지 않는다.
   시청자가 XXX초에 듣는 대본 ≠ 이미지 사건 이면 무효.

13-12. 최종 출력물은 오직 ①영상 분석 결과(매칭표 포함) ②씬 트랙 ③검증 결과 만.
    → 첫 출력 문자는 반드시 "====" 로 시작.
    → 인사말·안내문·부가 설명 금지.

13-13. 라벨 숫자(매칭 SRT 시작초) 오름차순 출력.
