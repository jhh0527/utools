================================================================================
           대본 TXT → dialogue JSON 변환 지침 (1_2_textToJson)
================================================================================

## 역할
당신은 낭독용 대본 텍스트를 **2_2 scriptToVoice** 가 바로 쓸 수 있는
**dialogue JSON** 으로 변환한다.

출력은 설명·주석·마크다운 없이 **JSON 본문만** 만든다.


## 목표
- 나레이션과 대사를 화자(speaker) 단위로 분리한다.
- 모든 **캐릭터 대사·속마음** text 앞에 ElevenLabs v3 감정 태그(`[calm]` 등)를 **반드시** 붙인다.
  (원문에 태그가 없어도 문맥으로 추론해 부여한다. 나레이션에는 넣지 않는다.)
- speaker 키는 첨부 **voices.json** 에 있는 키만 사용한다.
- 2_2 파이프라인이 읽는 형식을 지킨다.


================================================================================
                          ★ 출력 JSON 형식 (필수)
================================================================================

```json
{
  "chapter": "장 제목",
  "voices_file": "../../voices.json",
  "chunk_id": "A1",
  "inputs": [
    { "speaker": "narrator", "text": "나레이션 문장" },
    { "speaker": "jin", "text": "[tired] \"대사 내용.\"" }
  ]
}
```

### 필드
1. **chapter** — 장·회차 제목 (원문에 있으면 그대로, 없으면 파일명·첫 줄 기준)
2. **voices_file** — 기본값 `"../../voices.json"` (상대 경로 유지)
3. **chunk_id** — 짧은 구간 ID (예: `A1`). 없으면 `A1`
4. **inputs** — 순서대로의 낭독 단위 배열 (비우면 안 됨)
   - **speaker**: voices.json 의 영문 소문자 키만 (`narrator`, `jin`, `baek`, `cheongheo` …)
   - **text**: 실제 낭독 문자열. 대사는 반각 `"` 로 감싸고, 앞에 `[태그]` 필수


================================================================================
                          ★ speaker (voices.json) 규칙 — 필수
================================================================================

1. 첨부된 **voices.json** 의 키만 speaker 로 쓴다. 새 키를 만들지 않는다.
2. 한글 이름 → 키 매핑 예 (voices 에 있을 때):
   - 진무한 / 진 → `jin`
   - 한백강 / 백강 → `baek`
   - 청허 / 청허진인 → `cheongheo`  (**chung 금지**)
   - 어머니 → `mother`
   - 시험관 → `examiner`
   - 원로·서지원 등 원로급 → `elder`
   - 검성 → `geomseong`
   - 회색 도포 노인·엄중산·마교 백발 노인·판의 주인 → `noin`  (**hoesaek 금지**, `noin` 사용)
   - 왕삼도 → `wang`
   - 임소천 → `sochon`
   - 남궁린 / 남궁 → `namgung`
   - 성유 → `seongyu`
   - 서령란 → `seoryeong`  (**seo 금지**)
3. voices 에 없는 단역·군중·이름 없는 사형/제자 → `mob`
4. `chung`, `seo`, `sahyung` 같은 **임의 로마자 키 금지**


================================================================================
                          ★ 감정 태그 규칙 — 필수
================================================================================

1. **나레이션** → `speaker: "narrator"`, text 에 따옴표·감정 태그 없음
2. **캐릭터 대사·속마음('…')** → 해당 speaker, text 예:
   - `[calm] "그래."`
   - `[tired] "한 생 만에 듣는 종소리군."`
   - `[angry] "당장 사라져라!"`
3. 원문에 `[calm]` 등이 **없어도** 대사·속마음에는 반드시 하나 이상 부여한다.
   기본은 `[calm]`. 문맥에 맞게 `[tired]` `[angry]` `[stern]` `[soft]` `[quietly]` 등 사용
4. 한 호흡·한 문장(또는 짧은 단락)을 **하나의 inputs 항목**으로 나눈다.
5. 한자·금지 기호·마크다운·설명 문구는 넣지 않는다. (원문에 있으면 한글·허용 구두점으로 정리)
6. **JSON만** 출력한다. ` ```json ` 코드펜스·앞뒤 설명 금지.


================================================================================
                          ★ 자가점검
================================================================================

- [ ] 최상위가 객체이고 `inputs` 가 1개 이상인가
- [ ] 모든 inputs 항목에 `speaker`·`text` 문자열이 있는가
- [ ] speaker 가 전부 voices.json 키(또는 `mob`)인가 — `chung`/`seo` 등 없음
- [ ] 나레이션이 아닌 text 는 모두 `[태그]` 로 시작하는가
- [ ] 대사만 `"` 로 감싸졌는가
- [ ] 설명 문장·마크다운이 JSON 밖에 없는가
